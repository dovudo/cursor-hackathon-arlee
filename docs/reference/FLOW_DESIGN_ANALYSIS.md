## 🚨 Критические Issues

### Issue 1: Нет retry механизма

**Приоритет**: 🔴 Высокий

**Описание**: При временной недоступности API запрос просто падает.

**Решение**:
```typescript
async function withRetry<T>(
  fn: () => Promise<T>,
  maxRetries = 3,
  delay = 1000
): Promise<T> {
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await fn()
    } catch (error) {
      if (i === maxRetries - 1) throw error
      await new Promise(resolve => setTimeout(resolve, delay * (i + 1)))
    }
  }
  throw new Error('Max retries exceeded')
}
```

---

### Issue 2: Нет детального прогресса

**Приоритет**: 🟡 Средний

**Описание**: Пользователь не видит прогресс генерации каждой сцены.

**Решение**: Добавить polling статуса на фронтенде для каждой сцены отдельно.

---

### Issue 3: Синхронный polling блокирует

**Приоритет**: 🟡 Средний

**Описание**: Polling Replicate блокирует выполнение Edge Function до 2 минут.

**Решение**: Для MVP приемлемо, но можно улучшить через webhooks в будущем.
